Sigorta İptal Süreci API - V1
17/02/2023
Satın alınan herhangi bir sigorta ürünü için iade talebi oluşturmayı sağlayan bir REST API servisidir.
# API İstek Adresleri
Dokümantasyonda her fonksiyon için istek adresi ayrıca belirtilmiştir.
API Endpoint
Production Server: https://api.tamamliyo.com
Test Server: https://api-test.tamamliyo.com
# API Token
API erişiminin sağlanabilmesi için iş ortaklarımızla bir API token bilgisi paylaşmaktayız. Sizinle paylaşmış olduğumuz token değerini istek sırasında header bölgesinde “token” değeri ile göndermeniz gerekmektedir.
# Request ve Response
Bütün API hizmetimiz JSON formatıyla çalışmaktadır. İsteklerinizi JSON formatında göndermeniz gerektiği gibi, sonuçlarımız da (HTTP status code 200 -başarılı- dönmesi durumunda) JSON formatında verilmektedir.
İstek sırasında gönderdiğiniz parametrelerin veri tiplerinin, örnek requestteki gibi olmasına dikkat etmeniz gerekmektedir.
Integer alanları Integer, String alanları String tipiyle göndermeniz gerekir. REQUEST BODY sonuçlarımızda 3 genel parametre bulunmaktadır.
API Fonksiyonları
Bu ana başlık altında, API servisimizde kullanabileceğiniz fonksiyonları detaylarıyla birlikte öğrenebilirsiniz. Ayrıca aşağıda da fonksiyonlarımızla ilgili özet bilgi geçilmiştir.

POST
URL
