Travel API V3.2
18/03/2025
Seyahat sağlık sigortası için teklif oluşturma ve oluşturulan teklifi poliçeleştirmeyi sağlayan bir REST API servisidir.
# API İstek Adresleri
Dokümantasyonda her fonksiyon için istek adresi ayrıca belirtilmiştir.
API Endpoint
Production Server: https://api.tamamliyo.com
Test Server: https://api-test.tamamliyo.com
# API Token
API erişiminin sağlanabilmesi için iş ortaklarımızla bir API token bilgisi paylaşmaktayız. Sizinle paylaşmış olduğumuz token değerini istek sırasında header bölgesinde "token" değeri ile göndermeniz gerekmektedir.
# Request ve Response
Bütün API hizmetimiz JSON formatıyla çalışmaktadır. İsteklerinizi JSON formatında göndermeniz gerektiği gibi, sonuçlarımız da (HTTP status code 200 -başarılı- dönmesi durumunda) JSON formatında verilmektedir.
İstek sırasında gönderdiğiniz parametrelerin veri tiplerinin, örnek requestteki gibi olmasına dikkat etmeniz gerekmektedir.
Integer alanları Integer, String alanları String tipiyle göndermeniz gerekir. Response sonuçlarımızda 2 genel parametre bulunmaktadır.
# Teklif Alma ve Genel Süreç Hakkında Bilgilendirme
Herhangi bir kişisel bilgi paylaşmadan, doğrudan fiyat bilgisini elde etmek için "Fiyat al" servisimizi kullanabilirsiniz.
Teklif oluştur servisimiz üzerinden bir teklif oluşturabilirsiniz. Bu servisten dönen "teklifId" parametresiyle teklifin ödeme ve poliçeleştirme süreçlerini tamamlayabilirsiniz.
Teklif oluştur ve fiyat al servislerimiz üzerinden bir teklif veya fiyat almak istendiğinde, reuqest içerisinde urunKodu kullanmak yerine 'urun' key i ile işlemlerinizi gerçekleştirebilirsiniz. Bu kullanımın temel amacı aktif olarak kullanılan sigorta şirketinde oluşabilecek olası hatalara hızlı bir reaksiyon göstermemizi ve API üzerinden başarılı bir şekilde çalışmaya devam etmemize yardımcı olmaktır. Yurt ici teklif requestlerinde 'urun': 'yurtici-seyahat',  Yurt disi teklif requestlerinde 'urun':'yurtdisi-seyahat' kullanılması gerekmektedir. Örnek requestlere dokumanı inceleyerek ulaşabilirsiniz.

# Fiyat Al
Bu fonksiyon aracılığı ile bir seyahat sağlık sigortası teklifi oluşturmadan fiyat bilgisi alabilirsiniz.
Ürün kodları endpointimizden elde edeceğiniz urun_id değerlerini, body içinde urun_id parametresi ile göndererek istediğiniz ürünün fiyatlarını alabilirsiniz. urun_id parametresinin gönderimi zorunlu değildir.
eSiM
1.
                    ulkeKodu gönderildiği takdirde esim parametresi içinde ülkeye özel esim tekliflerine erişebilirsiniz.
2.
                    eSiM teklif fiyatları "amount" parametresi ile belirtilmiştir. Birimi ise "currency" parametresi ile belirtilmiştir.
3.
                    Satın alınan eSiM paketinin geçerli olacağı süre ise "validity_period" parametresi ile belirtilmiştir.
4. Paketin kaç GB olduğu "data_amount" parametresi ile belirtilmiştir.
5.
                    USD olarak gelen fiyatları EUR birimine dönüştürmek isterseniz Merkez Bankası`ndan çekilen veriler ile hesaplanan "usdEurRate" oranını kullanabilirsiniz.
Bilet İptal
1.
                    "parameters" içindeki"ticketType" parametresi otobüs:0, uçak:1, feribot:2 değlerine göre gönderilmelidir.
2. "parameters" içindeki"ticketPrice" parametresi biletin fiyatını belirtir.
3. "parameters" içindeki"company" parametresi biletin alındığı şirketi belirtir.
4.
                    "parameters" içindeki"departureLocation" parametresi biletin kalkış noktasını belirtir.
5.
                    "parameters" içindeki"departureAirport" parametresi biletin kalkış havaalanını belirtir. Sadece bilet tipi uçak olanlarda gönderilmelidir.
6. "parameters" içindeki"arrivalLocation" parametresi biletin varış noktasını belirtir.
7.
                    "parameters" içindeki"arrivalAirport" parametresi biletin varış havaalanını belirtir. Sadece bilet tipi uçak olanlarda gönderilmelidir.
8. "parameters" içindeki"departureDate" parametresi biletin kalkış tarihini belirtir.
9.
                    "parameters" içindeki"promosyonBilet" parametresi promosyon bilet olup olmadığını belirtir. True/False olarak gönderilebilir.
Rötar Koruma Paketi
1.
                    Uçak Rötar Koruma Paketi ve Sefer İptal Destek Paketi olarak iki hizmet bulunmaktadır.
2. Uçak Rötar Koruma Paketi sadece uçak seyahatleri için geçerlidir.
3. Sefer İptal Destek Paketi sadece Yunanistan için geçerlidir.

# Teklif Oluştur
Bu fonksiyon aracılığı ile bir seyahat sağlık sigortası teklifi oluşturabilirsiniz. Bir sigorta ettiren olması zorunludur. Birden fazla sigortalı eklenebilir.
Teklif oluşturma sürecinin başarılı olması durumunda "data" parametresinin altında kullanabileceğiniz; ürün bilgisi, teklif bilgisi gibi çeşitli bilgiler dönecektir. Bu teklifte saklamanız gereken en önemli değer teklifId parametresidir. Bir sonraki fonksiyonlarda kullanmak için ihtiyacınız olacaktır.
NOT: Yurtdışı teklif oluşturma sürecinde sigortası parametresinin içine girilen kişi sayısına göre hem grup hem de tek kişilik sigorta teklifi alınabilir
Ürün kodları endpointimizden elde edeceğiniz urun_id değerlerini, body içinde urun_id parametresi ile göndererek istediğiniz ürünün fiyatlarını alabilirsiniz. urun_id parametresinin gönderimi zorunlu değildir.
eSiM
1.
                    Fiyat-al servisinden alacağınız api_id değerlerini buradaki "api_id" parametresi içinde göndererek teklif alabilirsiniz.
2.
                    Birden çok eSiM seçimi yapıldıysa seçilenlerin api_id değerleri bir arada gönderilerek (["930","930","929"] gibi) birden çok teklif alınabilir.
Rötar Koruma Paketi
1.
                    Rötar Koruma Paketi almak isterseniz rotar_urun_id fiyat-al servisinden alınan rotar_urun_id değerini göndermeniz gerekmektedir.
2.

Fast Track API
# Genel Bakış
Fast Track API, havaalanlarında hızlı geçiş, lounge erişimi ve VIP hizmetler için kullanılır.
API üç ana endpoint içerir: fiyat sorgulama, satış oluşturma ve ödeme onaylama.
Tüm istekler için token authentication gereklidir.
